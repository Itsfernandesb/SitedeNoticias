# 📰 Site de Notícias

Projeto de um site de notícias sendo desenvolvido durante minha formação em Desenvolvimento Full Stack, com foco na construção de uma interface moderna, responsiva e organizada.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Componentização
* Design responsivo

## ✨ Funcionalidades

* Exibição de notícias em cards
* Organização das notícias por categorias
* Página para visualização de matérias
* Layout responsivo para diferentes tamanhos de tela
* Componentes reutilizáveis
* Navegação entre as diferentes seções do site
